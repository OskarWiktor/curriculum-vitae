## CV Website

A minimalist, responsive CV website created for the purpose of the recruitment process.

### Technologies

- Next.js
- TypeScript
- Tailwind CSS
- React Icons

### Tasks

- UI design and implementation
- Dynamic routing
- Language switcher (PL/EN)
- Styling with Tailwind
- Font scaling system
- Shared components
- Accessibility improvements
